# ماسح QR والباركود

تطبيق Flutter لقراءة رموز QR والباركود باستخدام كاميرا الهاتف.

## الميزات
- مسح تلقائي للرموز المدعومة من مكتبة `mobile_scanner`.
- تشغيل الفلاش والتبديل بين الكاميرات.
- حفظ آخر 80 نتيجة محلياً على الجهاز.
- البحث في سجل المسح وحذف عنصر بالسحب.
- نسخ نتيجة المسح وفتح الروابط الآمنة عبر المتصفح الخارجي.
- اهتزاز خفيف عند نجاح القراءة ومنع فتح النتيجة نفسها بشكل متكرر أثناء المعالجة.
- واجهة داكنة باللغة العربية واتجاه من اليمين إلى اليسار.

## التشغيل
1. ثبّت Flutter وAndroid SDK.
2. افتح مجلد المشروع الذي يحتوي `pubspec.yaml`.
3. نفّذ `flutter pub get`.
4. شغّل `flutter run` أو أنشئ APK باستخدام `flutter build apk --release`.

يتطلب التطبيق إذن الكاميرا. لا يمكن التحقق من تشغيل الكاميرا أو بناء APK في هذه البيئة لعدم توفر Flutter SDK هنا.
